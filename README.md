# Chameleon — Releases

Built installers for [Chameleon](https://github.com/BaderBader93/Chameleon-App).
No source here; this repository exists only to carry the binaries, which are too
large to live in git (GitHub rejects any file over 100 MB, and both installers
are above it).

Downloads are on the [Releases](../../releases) page.

| | |
|---|---|
| macOS | Apple Silicon only, macOS 11+. Open the `.dmg`, drag Chameleon onto Applications. |
| Windows | x64, Windows 10 build 19041 (version 2004) or newer. Run the `.exe`. |

Neither build is signed with a paid certificate, so the first launch is blocked
on both platforms — on macOS right-click the app and choose Open; on Windows
choose More info, then Run anyway. Once only.

This repository is private. Its release assets are reachable by collaborators.
